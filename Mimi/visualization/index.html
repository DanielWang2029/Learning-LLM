Mimi — Streaming Neural Audio Codec

The audio tokenizer behind Moshi and Hibiki (simultaneous speech-to-speech translation). A causal convolutional encoder/decoder maps a waveform to 12.5 Hz discrete tokens and back, in a fully streaming fashion, using a split residual VQ that fuses a distilled semantic codebook with parallel acoustic codebooks.

Scalable bitrate — the residual-VQ property

More residual codebooks reconstruct the encoder latent monotonically better; one codec serves many bitrates (measured on the RVQ latent reconstruction).

Semantic distillation (codebook #1)

Cosine alignment of codebook #1 to the semantic target rises far above an untrained baseline — the split-RVQ mechanism that gives the tokens meaning (§3.3.2).

WavLM has no CPU stand-in, so the target is a transparent proxy (a fixed embedding of the ground-truth vowel class). Full phonetic separability needs the paper's WavLM teacher + scale.

Streaming == offline

Causal conv state carried chunk-by-chunk exactly reproduces the full-sequence pass — the codec is genuinely streaming.
