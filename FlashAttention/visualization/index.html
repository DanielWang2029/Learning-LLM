FlashAttention

Exact attention, computed block by block with an online softmax so the full N×N score matrix is never stored. Same numbers as standard attention, a tiny fraction of the memory.

Dao et al., 2022 arXiv:2205.14135 Tiling Online softmax IO-aware

1 · The problem, and the trick

Standard attention materializes N×N

The score matrix S = QKᵀ has one entry per (query, key) pair. Its size grows with the square of the sequence length — the memory bottleneck FlashAttention removes.

sequence length N = 8
full N×N score matrix (naive) one block tile FlashAttention holds at a time

Online softmax (paper Alg. 1)

for each key block j: S = Q_i · K_jᵀ / √d # one small tile m_new = max(m, rowmax(S)) p = exp(S − m_new) l = exp(m − m_new)·l + Σ p O = exp(m − m_new)·O + p·V_j m = m_new O_i = O / l # exact softmax, streamed

Two running scalars per query row — the max m and normalizer l — let the softmax be computed incrementally and rescaled as new blocks arrive. Nothing but a single tile is ever in memory.
