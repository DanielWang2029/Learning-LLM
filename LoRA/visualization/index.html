LoRA — Low-Rank Adaptation

Freeze the pretrained weight W₀ and learn a tiny low-rank update ΔW = B·A. Same accuracy as full fine-tuning, ~100× fewer trainable parameters, and the adapter folds into W₀ with zero extra inference cost.

Hu et al., 2021 arXiv:2106.09685 ΔW = B·A Parameter-efficient fine-tuning

The core idea: ΔW = B·A

A full-rank update to a big out×in weight matrix is replaced by the product of two skinny matrices. Only the colored factors A and B train; the grey matrix W₀ stays frozen.

W₀ frozen (no gradients) B trainable (init 0) A trainable (init N(0,·))
h = W₀·x + b + (alpha / r) · (B · A) · x with r ≪ min(in, out) B = 0 at init ⇒ ΔW = 0 ⇒ the adapted model starts exactly at the pretrained model.

Trainable parameters: full fine-tuning vs LoRA

Across the whole model. LoRA's trainable count is a sliver of full fine-tuning — the headline efficiency win (baked in from the demo run).

Accuracy on the new task

The frozen model is useless on the new task (near chance). LoRA recovers almost all of full fine-tuning's accuracy while training ~100× fewer parameters.

Merge, unmerge & swap

Because ΔW = (alpha/r)·B·A is just a matrix, it can be folded into W₀ for deployment (no extra latency), removed exactly, or swapped off to restore the base model.
