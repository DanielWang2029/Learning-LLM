Position equations

d = q − k same chunk: d′ = d adjacent, d ≤ window: d′ = d far chunks: d′ = C + ((q mod C) − (k mod C)) mod C attention = softmax(content(q,k) + bias[d′])

Chunk size C=32 here. The production paper combines DCA with YaRN attention scaling; this compact demo isolates DCA.
