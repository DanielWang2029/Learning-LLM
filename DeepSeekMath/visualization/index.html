GRPO — Group Relative Policy Optimization

The critic-free RL algorithm introduced in DeepSeekMath. Instead of PPO's value network, GRPO samples a group of outputs per prompt and uses the group's own reward statistics as the baseline. A tiny Transformer policy here learns to add from reward alone.

DeepSeek-AI, 2024 arXiv:2402.03300 No value network Group-relative advantage KL to reference

The GRPO loop

One optimization step, four stages — repeated until the policy reliably earns reward.

1

Sample a group

For each prompt, sample G completions from the current policy — the exploration that GRPO learns from.

2

Score each

A rule-based reward scores every completion (here: 1.0 for the correct sum).

3

Normalize within group

A_i = (R_i − mean) / (std + eps) — the group is its own baseline. No critic.

4

Clipped + KL update

PPO-style clipped ratio × advantage, minus a KL penalty to a frozen reference.

The objective

A_i = (R_i − mean(R)) / (std(R) + eps) (Eq. 20) r_{i,t} = π_θ(o_{i,t}) / π_θ_old(o_{i,t}) (ratio) J = mean_i mean_t [ min( r·A_i, clip(r,1±ε)·A_i ) (Eq. 21) − β · D_KL(π_θ ‖ π_ref) ] D_KL ≈ π_ref/π_θ − log(π_ref/π_θ) − 1 (unbiased)
