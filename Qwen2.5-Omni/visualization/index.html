Qwen2.5-Omni

The streaming audio encoder: instead of full attention over the whole clip, it attends in independent 2-second blocks (block-diagonal attention). This decouples perception from long-sequence modeling and enables chunked, bounded-latency streaming prefill.

Block-diagonal attention

Each frame attends only to frames in its own 2-second block. The mask below (small example) is what turns O(T²) full attention into O(T·block).

Attention mask (allowed = bright)

Rows/cols are encoder frames; the block-diagonal structure means blocks never see each other — so they can be computed independently and streamed.

How the encoder feeds the model

Perception (block-wise encoder) is decoupled from long-sequence modeling (the LLM). Blocks are stacked on a batch axis, encoded in parallel, then concatenated.

TMRoPE gives audio one temporal position id per 40 ms; the Thinker–Talker split lets text and speech be generated together. Both are described in the README.

Block-wise closely approximates full attention

Same trained weights, evaluated with different block sizes. Downstream per-frame recognition accuracy is identical to full attention; the raw embeddings converge to the full-attention ones as the block grows (cosine → 1).
