Llama 2 — Grouped-Query Attention

Llama 2 keeps the LLaMA recipe (RMSNorm · RoPE · SwiGLU) and adds Grouped-Query Attention (GQA): query heads share key/value heads in groups, shrinking the decode-time KV cache with near multi-head quality. Below: how MHA, GQA and MQA share K/V heads, and what that saves in memory.

Cyan = query heads, red = key/value heads. Lines show which query heads read from which K/V head. Fewer K/V heads → smaller KV cache.

The Llama 2-Chat alignment pipeline (high level)

Beyond architecture, Llama 2-Chat is aligned with a multi-stage RLHF pipeline (paper Section 3). This repo implements the architecture; the pipeline is summarized here for context.

1 · Pretrain
Base LLM

Decoder-only model (this repo) trained on ~2T tokens of public text.

2 · SFT
Supervised fine-tuning

Fine-tune on high-quality instruction/response demonstrations.

3 · Reward models
Helpfulness + Safety

Two reward models trained on human preference comparisons.

4 · RLHF
Rejection sampling + PPO

Optimize the policy against the reward models, iteratively.

→
Llama 2-Chat

A helpful, safer conversational model.
