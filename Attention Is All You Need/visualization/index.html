The architecture, end to end

Two stacks of N identical layers. The encoder maps the input sequence to a set of continuous representations; the decoder generates the output one token at a time, attending to both its own past and the encoder's output.

    How attention is computed

    The single mechanism the whole paper rests on — no recurrence, no convolution.

    Scaled Dot-Product Attention §3.2.1

    Compare every query with every key, scale, softmax, then take a weighted sum of the values.

    Attention(Q, K, V) = softmax( Q·Kᵀ / √d_k ) · V Q : (·, seq_q, d_k) queries K : (·, seq_k, d_k) keys V : (·, seq_k, d_v) values mask → set disallowed scores to −∞ before softmax
    • The √d_k scaling keeps dot products from growing large and pushing softmax into tiny-gradient regions.
    • The mask is how the decoder stays causal and how padding is ignored.

    Multi-Head Attention §3.2.2

    Run attention h times in parallel on learned projections, then concatenate.

    head_i = Attention(Q·Wᵢ^Q, K·Wᵢ^K, V·Wᵢ^V) MultiHead(Q,K,V) = Concat(head_1..head_h) · W^O d_k = d_v = d_model / h (base model: 512 / 8 = 64)
    • Each head can specialize — e.g. one tracks position, another tracks syntax.
    • Total cost is similar to single-head attention at full dimension.

    Positional encoding

    Attention alone is order-agnostic, so the paper injects position with fixed sine/cosine waves of geometrically increasing wavelength (§3.5). Each curve below is one embedding dimension across positions.

    PE(pos, 2i) = sin(pos / 10000^(2i/d_model))    PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))
