The delta rule: read, compare, write

Read the current value along a direction, compare it to a target, and write back a gated rank-1 correction. This single move powers both faces of the paper.

Face 1 — Associative memory: store once, recall

Face 2 — Depth-wise DDL: correcting the residual across layers

Deep Delta Learning applies the same rule down the residual stream. Its signature property (Eq. 2.4): one rewrite scales the selected-readout error by exactly (1 − β) — identity at β=0, exact overwrite at β=1, over-relaxed for 1<β<2.

e_post = (1 − β) · e_pre  

Readout error vs depth

Stacking DDL layers drives a readout to its target; the error contracts by (1−β) per layer.
