Uni-ASR

One model — causal Conformer encoder + adapter + LLM decoder — for both non-streaming and streaming ASR, trained on interleaved speech-text sequences. Its latest-token fallback re-decodes the provisional last token of each chunk once the next chunk arrives, fixing boundary errors at no added latency.

Architecture & interleaved sequence

Speech is aligned to text and interleaved; the loss is taken only on the text targets (§2.2.2). Each speech segment a_j pools the encoder frames of token j that have arrived so far.

Latest-token fallback vs naive chunked decoding

At a chunk boundary the last token's acoustic nucleus may not have arrived yet. Naive decoding commits the guess; fallback re-decodes it after the next chunk. Both emit the same tokens at the same time — equal latency.

Streaming token error by chunk size

Pink = naive, green = with fallback. Chunk sizes that are multiples of the 160 ms token length never split a token, so naive already has no error there.
