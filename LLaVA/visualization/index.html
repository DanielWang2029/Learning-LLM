LLaVA · Visual Instruction Tuning

Connect a frozen vision encoder to a language model with one small learned projection, then instruction-tune. The LM learns to answer questions about images. Ablate the projection and the model goes blind — proving the projection is the entire bridge between seeing and speaking.

Liu et al., 2023 arXiv 2304.08485 frozen vision + learned projection instruction tuning

The projection is the bridge

With the projection trained, accuracy is high. Zero it out (ablate) or train without any visual input (blind), and accuracy collapses to chance.

Why it works

Frozen vision, learned projection

  • The vision tower is never trained — it's a fixed feature extractor, exactly as LLaVA freezes CLIP.
  • The only new visual parameter is the projection W (LLaVA-1.5 uses an MLP, as here).
  • Instruction tuning teaches the LM to use those projected tokens to follow the question.

What the ablation proves

  • Zeroing the projection removes all visual signal; the LM can only guess from the question type.
  • Accuracy falls from ~96% to ~28% (chance ≈ 25–33%).
  • So the learned projection — not the LM, not the frozen encoder — is what makes the model see.
