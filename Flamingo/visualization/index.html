Flamingo: a Visual Language Model for Few-Shot Learning

Take a frozen language model and teach it to see — without touching its weights. Flamingo inserts new gated cross-attention layers between the LM blocks, initialized so the model starts as the pure LM and smoothly "opens up" to visual input during training.

    The tanh gating mechanism

    This is Flamingo's key trick (§2.2, Fig 4): each new sub-layer is scaled by tanh(α) with α initialized to 0, so at the start the layers are the identity and the model is exactly the pretrained LM. Training grows α to let vision in.

    Gated cross-attention + FFN §2.2

    y = x + tanh(α_attn) · CrossAttn(x, visual_tokens) y = y + tanh(α_ff) · FFN(y) α_attn, α_ff initialized to 0 → tanh(0) = 0 → y = x
    • At init the block is a no-op: Flamingo == the frozen LM.
    • As α grows, visual information is blended in gradually and stably.
