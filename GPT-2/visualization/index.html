The model is trained purely as a character-level LM on lines like task: input = output;. At test time we prompt it with an unseen input and let it generate the answer. Every task uses the same LM head.

The scale story & zero-shot framing

Why "framing" matters

p(output | "task: input =") = Π p(char | context)

GPT-2's claim is that a task is just a conditional distribution the LM already models. Describe the task in natural language and the answer is simply the most likely continuation. GPT-2 showed this gets dramatically better with scale (1.5B params, 40GB of text); here we show the mechanism at tiny scale.
