The retrieval task

d d d ... <NEEDLE> v ... d d <QUERY> → v • haystack = random distractor tokens • needle = <NEEDLE> marker + a secret value • the model must locate the marker anywhere in the context and copy the token after it

RoPE attention lets the model resolve positions in contexts longer than any it trained on — the last two columns are longer-than-trained haystacks. Implemented in src/task.py and src/model.py.

Sparse Mixture-of-Experts routing

Each token is routed to top-k of the experts by a learned router; the load-balancing loss keeps the router from collapsing onto a few experts. Bars show the measured per-expert load.

Top-k routing

Tokens (top) are dispatched to their top-k experts (bottom). Per-token compute stays fixed as experts are added.

Load balancing (ideal = each)

route: probs = softmax(x · W_router) top-k experts, gated by renormalized probs loss_aux = α · E · Σ_i load_i · importance_i (minimized when load is uniform)

Measured loads are near the ideal, so no expert is starved or overloaded. Implemented in src/moe.py → SparseMoE.
