Cache-Aware Streaming Conformer

Stream audio chunk-by-chunk while caching self-attention keys/values and convolution state across chunks. No past frame is recomputed, the streaming output is identical to a full forward pass, and one model runs at many latencies.

Noroozi et al., 2023 arXiv:2312.17279 KV cache + conv cache streaming == offline CPU demo

Streaming with caches

Each new chunk (cyan) is processed against cached history: the KV cache (pink) feeds self-attention; the conv cache (green) feeds the causal depthwise convolution. With a bounded left context the cache size — and per-chunk compute — stops growing.
