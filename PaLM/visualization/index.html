The PaLM block, end to end

A stack of identical decoder blocks. Unlike a standard Transformer, attention and the feed-forward network read from the same normalized input and their outputs are summed together onto the residual stream — the parallel formulation.

    Parallel vs. serial layers

    The single change with the biggest systems impact. PaLM reported ~15% faster training at scale with no quality loss for large models.

    Standard (serial) original Transformer

    y = x + Attention(LayerNorm₁(x)) z = y + MLP(LayerNorm₂(y)) # MLP must WAIT for attention to finish # two separate layer norms

    PaLM (parallel) this repo

    z = x + Attention(LayerNorm(x)) + MLP(LayerNorm(x)) # ONE shared layer norm # Attention and MLP run independently, then sum # their input projections can be fused

    Multi-Query Attention — one shared K/V head

    Every query head has its own projection, but all of them attend over a single shared key/value head. Same quality, far smaller KV cache at generation time.

    4 query heads (Q)
    →
    1 shared K/V head

    In code (src/attention.py): w_q → n_heads·head_dim, but w_k, w_v → head_dim only. The single K/V head is broadcast across all query heads with expand (no extra memory).
