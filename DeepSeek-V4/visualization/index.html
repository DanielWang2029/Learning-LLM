DeepSeek-V4 · Muon Optimizer

Muon steps 2-D weight matrices by orthogonalizing the momentum before applying it — approximating M = UΣVᵀ by UVᵀ so every singular direction moves equally. The orthogonalization is done with hybrid Newton–Schulz iterations, no SVD required.

The Muon update (Algorithm 1, §2.4)

Per matrix weight W

  1. Gₜ = ∇L(Wₜ₋₁) — gradient
  2. Mₜ = μ·Mₜ₋₁ + Gₜ — momentum buffer
  3. O′ = HybridNewtonSchulz(μ·Mₜ + Gₜ) — Nesterov + orthogonalize
  4. O = O′ · √max(n,m) · γ — rescale update RMS
  5. Wₜ = Wₜ₋₁·(1 − ηλ) − η·O — decay + step

1-D parameters (biases, norms, embeddings) fall back to Adam, exactly as the paper prescribes.

  • First normalize M₀ = M / ‖M‖_F so σ_max ≤ 1.

Bonus: mHC residual constraint (§2.2)

Manifold-Constrained Hyper-Connections keep the residual-mixing matrix doubly-stochastic (rows and columns sum to 1, entries ≥ 0), making it non-expansive so deep stacks stay stable. Implemented via Sinkhorn projection in src/mhc.py.
