ReAct

Synergize reasoning and acting: the agent alternates Thought → Action (a real tool call) → Observation, using each observation to decide its next step. Reasoning without tools hallucinates; acting without reasoning can't chain.

The two tools

Lookup[entity, attribute] — query the key-value knowledge base (e.g. Alice.country = France).

Calc[expression] — evaluate arithmetic (e.g. 68+214 = 282).

  • Reasoning-only can't query facts, so it guesses from stale memory and hallucinates.
  • Acting-only fires one naive tool call and can't chain lookup → lookup → calc.
  • ReAct reasons about each observation to choose the next action, so multi-hop questions fall out naturally.
Interactive companion to “ReAct: Synergizing Reasoning and Acting in Language Models” (Yao et al., 2022). The policy is a transparent rule-based stand-in for the paper's LLM, but the tools and observations are real; trace recorded by demo/run_demo.py.
