Multi-Head Latent Attention (MLA)

Keys and values are compressed into a small latent that is what gets cached, then up-projected on the fly. A decoupled RoPE key carries position. Result: a much smaller KV cache at matched quality.

DeepSeekMoE

Many fine-grained experts (top-k routed) plus an always-on shared expert. Balanced without an auxiliary loss via a per-expert routing bias. Bars show the measured routed-expert load.

Experts & routing

shared (always on) + routed (top-). Ideal routed load ≈ each.

Why fine-grained + shared

output = Σ_shared expert_s(x) (common knowledge) + Σ_{routed top-k} gate · expert_r(x) (specialists) balance: route_bias += speed · (target − load) (auxiliary-loss-free; no gradient)

Fine slicing lets the router compose precise per-token expert mixtures; the shared expert absorbs common patterns so routed experts specialize. In src/moe.py.

Multi-Token Prediction (MTP)

Besides the usual next-token head, an MTP module predicts the token two steps ahead from the same position — densifying the signal and enabling speculative decoding.
