QLoRA — 4-bit base + LoRA

Store the frozen base weights in 4-bit NormalFloat, dequantize them on the fly for the matmul, and train only small full-precision LoRA adapters on top. Big memory savings, accuracy retained.

NF4: the 16 quantization levels

Each weight is normalized into [-1, 1] by its block's absmax, then snapped to the nearest of these 16 levels — the quantiles of a standard normal (denser near 0, where weights cluster). Only the 4-bit index is stored.
