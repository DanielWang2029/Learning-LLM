LLaDA — Large Language Diffusion Models

A language model that does not generate left-to-right. It learns by masking tokens and predicting them with a bidirectional Transformer, then generates by starting from an all-[MASK] sequence and iteratively unmasking. Everything below is driven by a real model trained on CPU in this folder.

Nie et al., 2025 arXiv:2502.09992 Masked Diffusion Non-Autoregressive Bidirectional

Masked diffusion vs. autoregressive generation

An autoregressive model (GPT-style) commits tokens strictly left-to-right, each conditioned only on the past. LLaDA instead fills tokens in confidence order, conditioning every prediction on the whole sequence at once — the same forward/reverse idea as image diffusion, but the "noise" is masking.

LLaDA masked diffusion

forward: randomly mask a fraction t of tokens · reverse: predict all masked tokens, commit the most confident, re-mask the rest.

Autoregressive left-to-right

each token is produced in order; position i may only look at positions < i (a causal mask).

The three equations

Forward masking process (paper §2.1)

Pick a masking ratio, then mask each token independently.

t ~ U(0, 1] x_t[i] = [MASK] with prob. t = x_0[i] with prob. 1 - t t = 1 → fully masked t → 0 → original text

Training objective (paper §2.2, Eq. 3)

A single bidirectional network predicts the masked tokens; cross-entropy on masked positions, 1/t weighted.

L(θ) = − E_t E_x0 E_xt [ (1/t) · Σ_masked log p_θ(x0[i] | x_t) ] no causal mask → every position sees every other position

Reverse process — iterative unmasking (paper §2.4)

Generation runs the network T times. At each step it predicts every masked token, commits the highest-confidence predictions, and leaves the rest masked (“low-confidence remasking”).

x_T = [MASK]…[MASK] for step = 1 … T: p = p_θ( x0 | x_current ) # predict ALL masked positions at once commit the most-confident predictions # they become visible keep the least-confident ones masked # revisited on later steps return x_0

Reconstruction — fill the blanks in one shot

A different test: take a real periodic sequence, mask half of it, and let the bidirectional model fill every blank simultaneously. It recovers the original by reading structure from both sides of each gap.
