CLIP: Learning from Natural Language Supervision

A dual encoder — one for images, one for text — trained so that matching (image, caption) pairs land next to each other in a shared embedding space. Once trained, it classifies images it has never been told the labels of, zero-shot, just by comparing to captions.

Radford et al., 2021 arXiv:2103.00020 Contrastive (symmetric InfoNCE) Zero-shot transfer

    How the contrastive objective works

    The single idea behind CLIP: pull matched pairs together, push mismatched pairs apart — in both directions at once.

    Temperature-scaled cosine similarity §2.2

    Every image is scored against every caption in the batch.

    e_img = normalize(f_image(image)) e_txt = normalize(f_text(caption)) logits[i, j] = exp(t) · <e_img_i, e_txt_j> (t = learned log-temperature)
    • Cosine similarity lives in [−1, 1]; the temperature sharpens it.
    • The diagonal holds the N correct pairs; everything off-diagonal is a negative.

    Symmetric InfoNCE loss Fig 3

    Cross-entropy over rows (image→text) and columns (text→image), averaged.

    labels = [0, 1, …, N−1] L = ½·CE(logits, labels) # each image picks its caption + ½·CE(logitsᵀ, labels) # each caption picks its image
    • No hand-built class labels — supervision comes entirely from pairing.
    • Identical to the pseudocode in the paper's Figure 3.
