Nemotron 3.5 ASR — cache-aware streaming

A Cache-Aware FastConformer-RNNT model that transcribes speech in configurable chunk sizes chosen at inference — with no retraining. One model gives you the whole latency / accuracy Pareto curve, and a language-ID prompt steers transcription from a single multilingual model.

NVIDIA · 2026 model card (no formal paper) FastConformer-CacheAware-RNNT chunks: 80 / 160 / 320 / 560 / 1120 ms Language-ID prompt

This page reproduces the model card's mechanisms at small scale on CPU. Numbers below are baked in from a real run of demo/run_demo.py (a tiny FastConformer-RNNT trained on synthetic multilingual audio). Serve over http to load live data.

The architecture

An 8× depthwise-separable convolutional front-end subsamples audio to 80 ms encoder frames. Cache-aware Conformer blocks attend over full left context (the reusable cache) and a configurable right context R (the streaming lookahead). A one-hot language vector is broadcast across time, concatenated, and projected; an RNN-T decoder emits tokens.

Because attention right-context is bounded by R per layer and the conv path is strictly causal, an encoder frame depends only on inputs up to t + N·R frames ahead — so cached streaming is numerically identical to a full pass.

(a) Cache-aware streaming == full context

Streaming processes non-overlapping chunks and reuses cached state; a frame is finalized once its right context (N·R encoder frames, where N = number of Conformer layers) has arrived. The assembled streaming output matches a single full-context pass to floating-point precision — the model card's "no redundant overlapping computation."

max |streaming − full| across all frames, at three right-context settings. Effectively zero.

(b) One model, every chunk size: the latency / accuracy Pareto

The same trained model is evaluated at each chunk size — no retraining. Under a streaming emission-latency budget, a larger chunk lets the decoder integrate more of each (noisy) phone before committing, so accuracy rises with latency. Offline (unbounded latency) accuracy is the dashed ceiling.
