The Conformer block

A "sandwich" of four modules, each a pre-norm residual. Two half-step feed-forward modules bracket attention and convolution (the Macaron structure, Section 2.2).

    Inside the convolution module

    This is what makes a Conformer more than a Transformer — a gated depthwise convolution gives every channel a local temporal receptive field (Section 2.2, Fig. 2).

    LayerNorm→ Pointwise Conv ×2→ GLU→ Depthwise Conv (k=15)→ BatchNorm→ Swish→ Pointwise Conv→ Dropout
    Conv(x) = PW₂( Swish( BN( DepthwiseConv( GLU( PW₁(LayerNorm(x)) ) ) ) ) ) GLU(a, b) = a ⊙ σ(b) # split channels in half, gate one with the other Swish(x) = x · σ(x)

    Ablation: convolution and attention are complementary

    Measured on the demo task (per-frame tone classification). The label of each frame is (local tone + global key) mod K — it needs the local tone (convolution) and the global key stated once at the start (attention). Remove either and accuracy collapses (paper Section 3.4).
