The mechanism

Think more: append "Wait"

while steps < min_budget: if model wants to stop: suppress </think> emit "Wait" ← keep thinking take one more reasoning step
  • Overrides the model's premature stop and extends the reasoning chain.
  • Each "Wait" is one more unit of test-time compute.

Think less: force the end token

if steps ≥ max_budget: emit </think> ← stop now commit the current answer
  • Caps compute for speed — the other half of budget forcing.
  • Together they make test-time compute a simple dial.
