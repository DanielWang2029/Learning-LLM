Deep Reinforcement Learning from Human Preferences

Learn a reward function from preferences over trajectory segments — never from the reward itself — then optimize a policy against that learned reward. Here the "human" is simulated by a hidden true reward on a 5×5 gridworld, so everything is reproducible on CPU.

Christiano et al., 2017 arXiv:1706.03741 Bradley-Terry Reward learning Gridworld + value iteration

The preference-learning loop

The agent, the reward model, and the human form a loop. Crucially, the reward model is the only thing the human touches — and it sees only which segment is better, never a number.

1 · behavior

Trajectory segments

A policy produces short clips of states/actions (here a random walk over the grid).

2 · human

Preference label

Two segments are compared; the one with more hidden true reward is marked preferred (σ¹ ≻ σ²).

3 · reward model

Fit r̂ (Bradley-Terry)

Train r̂ so preferred segments get higher predicted return, via logistic loss.

4 · RL

Optimize policy

Plan a policy that maximizes the learned reward r̂ (value iteration).

↻ In the full paper these run concurrently; here we run them once, which already recovers the optimal policy.

The math

Bradley-Terry preference model Eq. 1

P(σ¹ ≻ σ²) = exp Σ r̂(σ¹) / ( exp Σ r̂(σ¹) + exp Σ r̂(σ²) ) = σ( Σr̂(σ¹) − Σr̂(σ²) ) loss(ψ) = − Σ_pairs [ μ¹ log P(σ¹≻σ²) + μ² log P(σ²≻σ¹) ] (μ = human label)

Because segments are equal length, preferences pin down r̂ only up to an affine transform — but for a discounted infinite-horizon MDP the optimal policy is invariant to exactly that, so the recovered reward still induces the right behavior.
