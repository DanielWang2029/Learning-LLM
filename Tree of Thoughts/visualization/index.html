Tree of Thoughts

Solving hard problems by searching a tree of partial solutions instead of committing to one chain. A thought generator proposes next steps, a state evaluator scores them, and a deliberate search explores promising branches and prunes dead ones.

Thought generator

⚖️

State evaluator

Judge each partial state sure / maybe / impossible. Impossible branches are pruned; promising ones are kept.

🔎

Deliberate search

BFS keeps a beam of the best states at each level and backtracks across branches — instead of one greedy line.

Why greedy fails

A greedy chain of thought picks the single best-looking operation and never reconsiders. If that early step leads to a dead end — as it often does — there is no way back. Tree-of-thoughts keeps several options alive at once and prunes only what is provably hopeless, so it finds the branch that reaches 24.

  • Greedy = tree search with beam width 1 and no backtracking.
  • Tree of Thoughts explores a beam of promising states per level.
  • The evaluator prunes impossible branches so search stays cheap (a handful of expansions per puzzle).
Interactive companion to “Tree of Thoughts: Deliberate Problem Solving with Large Language Models” (Yao et al., 2023). The generator/evaluator are transparent programmatic stand-ins for the paper's LLM prompts; the tree shown is a real search recorded by demo/run_demo.py.
