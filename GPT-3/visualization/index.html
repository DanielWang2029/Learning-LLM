GPT-3

Language Models are Few-Shot Learners. Put a few input→output demonstrations in the prompt and the model infers the rule and completes a new query — with no weight updates. Accuracy climbs as the number of shots K grows.

Learning from the prompt, not from training

Each rule is a permutation of the symbols. The rules overlap, so one demonstration is usually ambiguous — the model must accumulate evidence across shots to pin down the rule, then apply it to a symbol it was not shown.

A worked K-shot prompt

Green = demonstrations (the "shots"), orange = the query, cyan = the model's completion. The query symbol never appears among the demonstrations, so the model cannot copy — it has to infer the rule.

The rule family (memorized in the weights, selected by context)

During training the model saw all of these permutations. At inference the demonstrations tell it which one is active. Notice how columns share values across rows — that overlap is what makes single shots ambiguous.

How it works

In-context learning

prompt = x₁>y₁ x₂>y₂ … x_K>y_K x_q> answer = argmax p( · | prompt ) no parameter update — inference only

The knowledge of the rule family lives in the weights; the selection of the rule happens entirely in the forward pass, via attention over the demonstrations.

Induction heads

The mechanism behind this is the induction head: attention heads that look back for an earlier context matching the current one and copy what came next. More demonstrations give these heads more consistent evidence, so accuracy rises monotonically with K — exactly the trend plotted above.
