WeNet U2++

One shared encoder, trained with dynamic chunk masking, runs full-context or streaming. A streaming CTC first pass proposes hypotheses; bidirectional attention decoders rescore them in a second pass — improving accuracy using label context CTC cannot model.

Wu et al., 2021 arXiv:2106.05642 dynamic chunk training CTC + attention rescoring CPU demo

The two-pass architecture

The encoder is shared by all three heads. CTC runs frame-synchronously in the first pass (streaming); the L2R and R2L attention decoders rescore the CTC n-best in the second pass. Click a branch.

    Dynamic chunk masking — one model, any latency

    Each training batch picks a random chunk size. A frame may attend to all left history but only up to the end of its own chunk. A big chunk = offline; a small chunk = low-latency streaming. The same weights serve both.
