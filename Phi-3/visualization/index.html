Phi-3: Textbooks Are All You Need

Phi-3's thesis is that data quality beats data quantity. Here the same tiny language model, trained with the same compute, learns a clean "textbook" corpus far better than a 16× larger but systematically corrupted "web" corpus — measured on the same held-out clean test set. All numbers are real from this folder's demo.

Microsoft, 2024 arXiv 2404.14219 Data Quality Equal Compute

The experiment

Both datasets describe the deterministic rule next = (prev1 + prev2) mod V. The clean corpus follows it exactly. The noisy corpus is much larger but flatly contradicts the rule on ~40% of contexts (a consistent, repeated error — like web-scale misinformation). Everything else is held fixed.

Clean "textbook" vs noisy "web" samples

Each square is a token. In the noisy samples, red squares are positions where the corpus states the wrong next token (it violates the rule). These errors are consistent, so more data cannot average them away.
