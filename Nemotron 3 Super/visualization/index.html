Selective SSM recurrence (Mamba-2)

aₜ = exp(−Δₜ · exp(A)) # input-dependent decay Hₜ = aₜ · Hₜ₋₁ + xₜ · Bₜ # write token into state yₜ = ⟨Hₜ, Cₜ⟩ + D · xₜ # read state out
  • Fixed-size state H ⇒ O(L) time, O(1) memory per step.
  • Δ, B, C are functions of the token — the model selects what to keep.
  • Attention layers add O(L²) global mixing where it matters most.
