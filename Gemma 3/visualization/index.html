Gemma 3 · 5:1 Local:Global

Make most attention layers local (a cheap sliding window) and only a few global (full attention) — a 5:1 ratio. The rare global layers still relay long-range information, so accuracy holds while attention memory plummets. Plus QK-norm.

The 5:1 layer stack

Six layers, bottom to top. Five are local (attend within a small window); the top one is global (attends everywhere) to route long-range info.

■ local (sliding window) ■ global (full attention)

The retrieval task

A long sequence hides a MARK followed by a value; a QUERY at the end must recover it. Information has to travel the full length of the sequence.

Why it works

Local is cheap, global is powerful

  • A local layer computes only T·(2w+1) attention scores instead of T·T.
  • Stacking local layers grows the receptive field slowly — not enough to span a long sequence.
  • One global layer connects any two positions directly, so long-range retrieval just works.

QK-norm

q̂ = q / ‖q‖ k̂ = k / ‖k‖ scores = q̂ · k̂ᵀ # bounded logits
  • Normalizing queries and keys bounds the attention logits and stabilizes training.
  • Used throughout the stack in this demo (toggle in code via qk_norm).
