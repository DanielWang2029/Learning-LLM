Kimi k1.5 — RL for Reasoning with a Length Penalty

An SFT warm-start makes a model accurate — but it "overthinks", emitting long reasoning chains. Left alone, RL does not curb that. Kimi k1.5 adds a length penalty to the reward that trims chains toward the minimum actually needed without sacrificing accuracy ("long2short"). The curves below are from a real GRPO-style run in this folder.

The RL loop

For each problem we sample a group of completions, score them, standardize the reward within the group to get an advantage (GRPO — no value network), and update the policy. The reward is where the length penalty lives.

policy gradient
length reward (within each group; min_len,max_len = group's shortest/longest): lambda_i = 0.5 − (len_i − min_len) / (max_len − min_len) # shorter ⇒ higher len_reward_i = lambda_i if the answer is correct = min(0, lambda_i) otherwise # never reward length on wrong answers reward_i = correctness_i + w · len_reward_i # w = 0 turns the penalty off

Accuracy stays high — length only stays controlled with the penalty

Two RL runs from the same warm-started policy (accurate but overthinking). Accuracy holds steady in both. But only the length-penalty run pulls the average chain down toward the ~3 steps actually needed; without it, chains stay long — RL alone does not curb overthinking.
