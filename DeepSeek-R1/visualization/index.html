DeepSeek-R1 · GRPO

Reasoning, incentivized by reinforcement learning alone. A policy is rewarded only for using a <think>…<answer> format and getting the answer right — no supervised traces. Group-Relative Policy Optimization samples a group of outputs per prompt and uses the group's own average reward as the baseline (no value network).

DeepSeek-AI, 2025 arXiv:2501.12948 GRPO Reward = format + correctness

The GRPO loop: sample a group → relative advantage → update

For one prompt the policy samples several responses. Each gets a reward; the advantage is the reward minus the group mean (standardized). Above-average responses are made more likely, below-average ones less — a pure policy gradient, no critic.

The update, in one line

Group-relative advantage

Aᵢ = (rᵢ − mean(r₁…r_G)) / (std(r₁…r_G) + ε)
  • The group's own mean is the baseline — no value network to train.
  • Only relative quality inside a group matters.

Policy gradient

loss = − mean_i [ Aᵢ · log π(outputᵢ | prompt) ] − β·H(π)
  • Reinforce above-average outputs, suppress below-average ones.
  • The entropy term H(π) keeps exploration alive.
