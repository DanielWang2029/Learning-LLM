Mixtral of Experts

A sparse Mixture-of-Experts transformer: 8 expert MLPs and a router that sends each token to only its top-2 experts. Many parameters, few active per token. Every figure below is real data from this folder's demo run.

Top-2 routing for one token

The router scores all 8 experts with a softmax; the token is processed by the 2 highest-scoring experts, whose gate weights are renormalized to sum to 1.

Top-2 (Mixtral) vs Top-1 (Switch Transformers)

Both are sparse MoE. Switch routes each token to a single expert (top-1) for maximum sparsity; Mixtral routes to two (top-2), combining them for a bit more capacity per token at a modest compute increase. Everything else — 8 experts, a router, and a load-balancing loss — is shared.
