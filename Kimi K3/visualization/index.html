Kimi K3 · Kimi Delta Attention

KDA is a gated delta-rule linear attention: a fixed-size recurrent state is decayed by a channel-wise forget gate, then corrected with the delta rule. Constant memory, linear time — long context without an L×L matrix.

Kimi Team, 2026 arXiv:2607.24653 Delta Rule Linear Attention

The recurrent state update (Eq. 1, §2.1.1)

One fixed-size state Sₜ ∈ R^{dk×dv} carries all memory. Each token decays it, reads what it currently predicts for the key, and writes only the correction (the delta rule).

Sₜ = (I − βₜ kₜ kₜᵀ)·Diag(αₜ)·Sₜ₋₁ + βₜ kₜ vₜᵀ õₜ = Sₜᵀ qₜ αₜ ∈ (0,1)^dk : channel-wise forget gate βₜ ∈ (0,1) : delta-rule write strength
  • Fixed-size state ⇒ O(L) time, O(1) memory per step.
  • q, k are L2-normalized; q/k/v pass a ShortConv so a token can see its neighbor.

Delta rule, step by step

decayS̃ = Diag(αₜ)·Sₜ₋₁
readread = kₜᵀ S̃
write ΔSₜ = S̃ + βₜ·kₜ (vₜ − read)ᵀ
outputõₜ = Sₜᵀ qₜ

Only the prediction error vₜ − read is written, so old bindings are updated instead of overwritten — the key to reliable recall.
