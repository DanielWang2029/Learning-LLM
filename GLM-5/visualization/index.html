GLM-5 · DeepSeek Sparse Attention

GLM-5 replaces dense O(L²) attention with DSA: a cheap lightning indexer scores every key, and each query attends only to its top-k keys. Long-range dependencies are kept, but the expensive attention runs over a tiny fraction of the sequence.

The DSA pipeline

Only the indexer touches all L keys, and it is cheap (small dimension, few heads). The heavy softmax attention sees just the k selected keys per query — the paper reports ~1.5–2× less attention compute at 128K context with no quality loss.

Lightning indexer §2.1.1

A low-dimensional, few-head scorer — orders of magnitude cheaper than a real attention head.

I[t, s] = Σ_h w_h · ReLU( qᴵ[t,h] · kᴵ[s,h] ) select S(t) = TopK_s( I[t, :] ) # k indices
  • It "looks" at content to decide importance — unlike a fixed sliding window.
  • Trained (warm-up) so its top-k lands where dense attention already concentrates.

Sparse attention §2.1.1

Ordinary scaled dot-product attention, but restricted to the selected keys.

o[t] = Σ_{s∈S(t)} softmax( q[t]·k[s] / √d ) · v[s] cost per query: k keys (not L) compute saved : 1 − k / L
  • Because k is fixed, cost grows linearly with sequence length, not quadratically.
  • Lossless when S(t) contains the high-mass keys — see the measured recall below.
