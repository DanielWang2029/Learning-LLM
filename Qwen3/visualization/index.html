Why thinking helps

Thinking = execute the chain

value₀ = start valueₜ = step(valueₜ₋₁, opₜ) # one thinking token per op answer = value_min(budget, L)
  • Each step carries the running value forward — no need to collapse the whole chain at once.
  • If the budget runs out before the chain ends, the answer is premature (wrong).

Non-thinking = one shot

answer = f(start, op₁, op₂, …, op_L) # single forward pass
  • Must compose every operation mentally in one step — accuracy collapses as chains grow.
  • Fast and cheap, but far less reliable on multi-step problems.
